# Sheets Hologram — Live Data Command Center

A mobile-first futuristic dashboard for viewing published Google Sheets data in a neon holographic command center.

## Features
- Responsive Android and desktop layout
- Animated 3D holographic visualization
- Interactive charts and searchable/filterable data table
- Google Sheets published CSV connection
- Automatic refresh while connected
- CSV export and built-in demo data

## Connect Google Sheets
1. Open the Google Sheet.
2. Choose **File → Share → Publish to web**.
3. Select the sheet/tab and choose **Comma-separated values (.csv)**.
4. Copy the published CSV URL, paste it into the dashboard, and press **Connect**.

**Privacy:** A published CSV is publicly accessible to anyone with the link. Do not publish confidential or personal data. This app never asks for your Google password.
